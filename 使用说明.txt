ComfyUI-BarCensor 使用说明
================================================================================

用纯色 Bar（黑/白/自定义色）代替马赛克进行遮挡打码。
本扩展包含两个节点，菜单位置 cog -> 🧪AILab -> ▬BarCensor：

    BarCensor                     打码节点（纯色条遮挡）
    MaskMerge (Combine Overlaps)  把多张 mask 合并成一张，接在 BarCensor 前面


--------------------------------------------------------------------------------
一、安装
--------------------------------------------------------------------------------
1. 把整个 ComfyUI-BarCensor 文件夹放进：
       ComfyUI/custom_nodes/ComfyUI-BarCensor/
2. 重启 ComfyUI。
3. 依赖：numpy、torch、opencv-python（ComfyUI 自带，通常无需另行安装）。


--------------------------------------------------------------------------------
二、典型接线：多个检测器 -> 一次打码
--------------------------------------------------------------------------------
    检测器A ─┐
    检测器B ─┼─> MaskMerge ── 合成一张 mask ──> BarCensor ──> 打码后的图
    检测器C ─┘                                    ↑
    原图 ─────────────────────────────────────────┘

这样做的好处：
    1. 只需要跑一次打码，不用把多个 BarCensor 串起来；
    2. 不会因为串级而在已经打过码的地方再叠一层码；
    3. 重叠部分取 max，值始终是 1，不会出现 mask 叠加变亮的问题。

MaskMerge 接口
    输入：
        mask_a       必填，第一张 mask
        mask_b ~ mask_h   可选，最多再接 7 张（共 8 个槽位）
    输出：
        mask         合并后的一张 mask
        info         文本，回显合并了几张、各输入的帧数、输出尺寸、覆盖率

MaskMerge 参数
    operation（下拉，默认 union）—— 重叠处怎么算
        union         取最大值。任一输入遮到的像素都遮。（常用）
        intersection  取最小值。只有所有输入都遮到的才算。
        add           相加后截断到 1，重叠处更"实"。
        average       取平均，柔和过渡。

    batch_mode（下拉，默认 flatten）—— 多帧怎么合并
        flatten       所有输入、所有帧全部压平成一张单帧 mask。
                      例：[3,H,W] + [1,H,W] + [2,H,W] -> [1,H,W]
                      多个检测器各自输出不同数量的区域时，用这个。
        elementwise   第 i 帧与第 i 帧合并，保持帧数。
                      处理视频、且各输入帧数相同时，用这个。

    threshold（默认 0.0）—— 二值化阈值。填 0 表示不处理；
       设为 0.5 时，输出会被压成纯 0/1 的硬边 mask。
       检测器输出的软边 mask 想变硬边时用。

    说明：
        - 各输入尺寸不一致时，自动按最大尺寸做双线性缩放对齐。
        - 输入的 [H,W] 二维 mask 会自动补成 [1,H,W]。
        - 超过 8 张可级联：MaskMerge 的输出再接下一个 MaskMerge 的 mask_a。


--------------------------------------------------------------------------------
三、BarCensor 接口
--------------------------------------------------------------------------------
输入：
    image            必填，待处理图像
    mask             可选，遮挡区域。不接 mask 则对整张图铺条

输出：
    image            打码后的图像
    censor_mask      条本身的遮罩（可用于后续 inpaint 等）
    info             文本，回显本次实际用到的角度 / 条数 / 间距 / 条厚


--------------------------------------------------------------------------------
四、BarCensor 参数逐项说明
--------------------------------------------------------------------------------

bar_count  (INT, 默认 1)
    条的数量。
    = 1 时整块矩形填充整个区域；
    > 1 时在区域内等距排布多条平行条。

angle_mode  (下拉, 默认 auto_rect)  —— 决定 Bar #1 的基准角度从哪来
    auto_rect        对 mask 求「最小外接矩形」，取其长边相对 0 度的旋转角。
                     Bar 就沿着这个方向铺。推荐默认。
                     实测真实角度 0/25/-40/60 度时，识别误差 < 0.1 度。
    auto_pca         mask 像素分布的主轴方向（PCA）。备用自动方案，
                     与 auto_rect 结果接近，形状奇特的 mask 上会有差异，
                     可来回切换对比。
    horizontal       固定 0 度，水平条。视频中最稳。
    vertical         固定 90 度，垂直条。
    diagonal_down    固定 45 度，左上到右下的斜条（\）。
    diagonal_up      固定 -45 度，左下到右上的斜条（/）。
    manual           手动指定，角度由下面的 angle 决定。

angle  (FLOAT, 默认 0.0)
    仅 angle_mode = manual 时生效。0 = 水平，90 = 垂直，负数往另一边斜。

bar_orientation  (下拉, 默认 along_axis)  —— 条相对于主轴的朝向
    along_axis       条顺着 mask 主轴延伸。
                     宽遮罩（如双眼区域）-> 水平条；
                     但竖长遮罩（如站立人像）会得到竖直条。
    across_axis      条垂直于主轴（+90 度）。
                     竖长区域想要水平条，就选这一项。
    axis_plus_offset 主轴 + axis_offset 度，用于微调或风格化。

axis_offset  (FLOAT, 默认 0.0)
    仅 bar_orientation = axis_plus_offset 时生效的偏移角度。

    注：以上三者都会把最终角度归一化到 [-90, 90) 度，且整组条共用这一个角度，
        平行性由构造保证（实测多条之间角度差 0.000 度）。

bar_shape  (下拉, 默认 rectangle)  —— 条的形状
    rectangle        标准旋转矩形，直边直角。经典 censor bar 外观。
                     mask 只决定遮挡块的位置 / 角度 / 大小，不裁切形状。
    conform_mask     条被 mask 轮廓裁切，保留弧形有机边缘。

thickness_mode  (下拉, 默认 auto)  —— 条厚怎么定
    auto             条厚 = 间距 × thickness_ratio。
                     改动 bar_count 时条厚自动等比缩放，遮挡块整体大小不变。
                     例：块高 98px、ratio 0.8 时，
                         3 条 -> 条厚 26.5px
                         5 条 -> 条厚 15.7px
                         8 条 -> 条厚  9.8px
    manual           固定像素，由 bar_thickness 指定；
                     仍受「间距 × thickness_ratio」上限约束，防止条与条粘连。

thickness_ratio  (FLOAT, 默认 0.8)
    条厚占间距的比例。
    auto 模式：作为实际比例
    manual 模式：作为上限比例
    0.5 = 条和缝一样宽；0.8 = 条粗缝细。

bar_thickness  (INT, 默认 24)
    thickness_mode = manual 时的固定条厚（像素）。

length_mode  (下拉, 默认 fit_region)  —— 条的长度
    fit_region       长度取区域旋转外接框的跨度，条正好罩住区域。
    full_image       条贯穿整张图。漫画式通栏条用这个。

length_overflow  (INT, 默认 8)
    条两端向外多延伸的像素数，让条比 mask 盖得稍宽一点。

color  (下拉, 默认 black)
    black / white / gray / custom。
    选 custom 时用下面的 custom_color。

custom_color  (STRING, 默认 #000000)
    color = custom 时的十六进制色值，例如 #1a1a1a。

opacity  (FLOAT, 默认 1.0)
    条的不透明度。1.0 = 完全遮住；0.5 = 半透明，底下图像隐约可见。

feather  (INT, 默认 1)
    边缘羽化像素数。0 = 硬边；1 ≈ 抗锯齿；调大边缘更柔。

invert_mask  (BOOLEAN, 默认 False)
    反选 mask，改为遮挡 mask 之外的区域。

region_expand  (INT, 默认 4)
    bar_shape = rectangle     时：遮挡块四周外扩的像素数。
    bar_shape = conform_mask  时：mask 膨胀的像素数。


--------------------------------------------------------------------------------
五、BarCensor info 输出示例
--------------------------------------------------------------------------------
    axis = -90.0 deg [auto_rect] + across_axis -> bar angle = 0.0 deg  |
    bars = 4  |  block = 134 x 268 px  |  period = 67.0 px  |
    thickness = 53.6 px [auto]

    主轴 -90 度（竖长区域），选 across_axis 后条的朝向变成 0 度（水平条）。
    注意到的调配角度时可以拿它对照。


--------------------------------------------------------------------------------
六、常用组合
--------------------------------------------------------------------------------
遮眼睛 / 宽扁区域      auto_rect + along_axis + bar_count 1
整人像 / 竖长区域      auto_rect + across_axis
带倾斜的物件           auto_rect + along_axis（条自动跟着歪）
通栏黑条风格           horizontal + length_mode full_image
视频序列               angle_mode 用 manual 或 horizontal，
                      不要用 auto —— 逐帧估计会抖动


--------------------------------------------------------------------------------
七、注意事项
--------------------------------------------------------------------------------
1. 节点参数有增删时，workflow 里旧的 BarCensor 节点需要删除后重新添加才会刷新。
2. 若缺少 cv2，auto_rect / conform_mask / feather 会退化（feather 失效，
   auto_rect 回退到 PCA），其余功能不受影响。
3. 节点内部已做异常兜底，出错时原图直接通过，不会中断 workflow。
4. BarCensor 目前把整张 mask 当作「一个区域」处理：若合成后的 mask 里有
   几块彼此分离的区域，它会取一个同时罩住所有块的大外接框，中间的空隙也
   会被打到。若希望每块区域各自成组打码，需要再加「按连通域分组」的模式。
4. 参考实现：https://github.com/1038lab/ComfyUI-Mosaic
